## 1.1.1 安装 VS Code 和 PlatformIO

### 步骤 1：下载 VS Code

访问官网下载并安装 VS Code：https://code.visualstudio.com/

**各平台下载链接：**
- Windows: https://code.visualstudio.com/Download#windows
- macOS: https://code.visualstudio.com/Download#mac
- Linux (Ubuntu/Debian): https://code.visualstudio.com/Download#linux

**安装完成后启动 VS Code。**

### 步骤 2：安装 PlatformIO 插件

1. 打开 VS Code
2. 点击左侧活动栏的 **扩展** 图标（或按 `Ctrl+Shift+X` / macOS: `Cmd+Shift+X`）
3. 在搜索框输入 `PlatformIO IDE`
4. 找到 **PlatformIO IDE**（发布者：platformio），点击 **Install**

![PlatformIO 安装示意图](https://platformio.org/img/platformio-ide-vscode.png)

### 步骤 3：等待 PlatformIO 初始化

安装完成后，PlatformIO 会自动开始初始化：
- 下载平台核心文件
- 安装 Python 依赖
- 创建默认环境

首次启动大约需要 **5-10 分钟**，请耐心等待。底部状态栏显示 `PlatformIO: Ready` 即表示完成。

> **提示**：如果自动初始化失败，可以在 VS Code 中按 `Ctrl+Shift+P`（macOS: `Cmd+Shift+P`），输入 `PlatformIO: Rebuild PlatformIO Core` 手动重建。

## 1.1.2 安装 Python 3.10+

本项目后端使用 Python 3.12，固件编译也需要 Python 3.10+。

### Windows/macOS 安装

1. 访问 https://www.python.org/downloads/
2. 下载 **Python 3.10 或更高版本**（推荐 3.12）
3. 运行安装程序
4. **重要**：Windows 安装时勾选 **Add Python to PATH**

验证安装：
```bash
python --version
# 或
python3 --version
```

### Linux (Ubuntu/Debian) 安装

```bash
# 更新包索引
sudo apt update

# 安装 Python 3.12 及 pip、venv
sudo apt install python3.12 python3.12-venv python3.12-pip

# 验证版本
python3 --version  # 应显示 Python 3.12.x
```

> **注意**：某些 Linux 发行版默认 Python 版本较低，可使用 deadsnakes PPA 或 pyenv 安装新版。

## 1.1.3 安装 ESP32 USB 驱动

ESP32-S3 通过 USB 与电脑通信，需要安装正确的 USB 转串口驱动。

### 识别你的 ESP32-S3 板子

本项目使用的 **微雪 ESP32-S3-Touch-LCD-1.85C V2** 使用 **CP210x** 芯片。

**查看芯片型号的方法：**
- 查看板子上 USB 接口附近的芯片标识
- 或查看产品说明书

### Windows 驱动安装

**CP210x 驱动：**
1. 访问 https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
2. 下载 **CP210x Universal Windows Driver**
3. 解压后运行 `Silabs_CP210x_Universal_Windows_Installer.exe`

**CH340 驱动（如果板子使用 CH340）：**
1. 访问 https://www.wch.cn/downloads/CH341SER_ZIP.html
2. 下载并安装 CH341SER 驱动

### macOS 驱动安装

```bash
# 使用 Homebrew 安装 CP210x 驱动
brew install --cask silabs-labs-tools

# 或安装 CH340 驱动
brew install --cask wch-ch34x-usb-serial
```

### Linux 驱动安装

大多数 Linux 内核已内置 CP210x 和 CH340 驱动，无需额外安装。

**如遇权限问题**（无法访问串口）：
```bash
# 将当前用户加入 dialout 组
sudo usermod -a -G dialout $USER

# 注销并重新登录生效
# 或重启系统
```

### 验证驱动安装

1. 将 ESP32-S3 通过 USB 线连接电脑
2. 打开设备管理器（Windows）或运行 `ls /dev/tty.*`（macOS/Linux）
3. 应看到类似 `Silicon Labs CP210x USB Bridge` 或 `/dev/tty.SLAB_USBtoUART` 的设备

## 1.1.5 硬件准备清单

### 必需硬件

| 型号 | 说明 | 备注 |
|------|------|------|
| **ESP32-S3-Touch-LCD-1.85C V2** | 微雪一体化开发板 | 本项目核心硬件，V2 版使用 ES7210+ES8311 音频方案 |
| **USB-C 数据线** | 用于供电和烧录 | 需支持数据传输，非充电线 |

**购买链接参考：**
- 淘宝/天猫：搜索 "微雪 ESP32-S3-Touch-LCD-1.85C"
-  AliExpress: https://www.waveshare.com/esp32-s3-touch-lcd-1.85c.htm

### 可选硬件

| 型号 | 说明 | 用途 |
|------|------|------|
| **3.7V 锂电池** | 带 PH2.0 接口 | 便携供电 |
| **外壳** | 3D 打印或亚克力 | 保护和美观 |
| **杜邦线** | 母对母若干 | 调试和扩展 |

### 硬件版本说明

本项目针对 **V2 版** 硬件开发，V1 版已于 2026.1.30 停产。

**V1 与 V2 的主要区别：**
| 特性 | V1 | V2 |
|------|----|----|
| 音频 DAC | PCM5101 | ES8311 |
| 音频 ADC | 数字 MEMS 麦克风 | ES7210 + 双模拟麦克风 |
| 功放控制 | 无独立控制 | NS4150B (GPIO15) |

> **重要**：V1 和 V2 的音频引脚和初始化代码不同，请勿混用！

## 常见问题

**Q: PlatformIO 安装失败怎么办？**  
A: 尝试在 VS Code 终端运行 `PlatformIO: Rebuild PlatformIO Core`，或手动卸载后重新安装。

**Q: 找不到 ESP32 串口设备？**  
A: 检查 USB 线是否为数据线（有些线只支持充电），或尝试更换 USB 口/数据线。

**Q: 驱动安装后仍然无法识别？**  
A: 重启电脑后再试，某些驱动需要重启才能生效。
