## 3.5.1 任务描述

### 目标

完整地添加一个 **"摇头晃脑"表情**（用于表达困惑/疑问）。

这个实战会用到前面学的所有知识：
- 固件端：新表情定义、LVGL 动画
- 后端端：情绪检测
- 联调：测试完整链路

### 最终效果

- 当用户问问题时，猫咪摇头晃脑表示困惑
- 眼睛左右移动（像真的在摇头）
- 持续 3 秒后恢复平静

### 触发条件

- 后端检测到疑问句（包含"吗"、"呢"、"？"等）
- 返回 `confused` 情绪

### 步骤 4：实现困惑表情动画

```cpp
// cat_face.cpp

// 困惑表情：摇头动画
void CatFace::_setConfused() {
    Serial.println("[CatFace] 困惑表情：摇头开始");
    
    // 使用 LVGL 动画让眼睛 X 位置左右移动
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, _leftEye);
    
    // 左眼：从 X=113 移动到 X=103（向左 10px）
    lv_anim_set_values(&a, 113, 103);
    lv_anim_set_duration(&a, 300);  // 300ms 向左
    lv_anim_set_path_cb(&a, lv_anim_path_ease_in_out);
    lv_anim_set_exec_cb(&a, _setEyeX);  // 设置 X 坐标回调
    lv_anim_set_completed_cb(&a, _confusedLeftDone);
    lv_anim_start(&a);
    
    // 右眼对称：从 X=247 移动到 X=257（向右 10px）
    lv_anim_init(&a);
    lv_anim_set_var(&a, _rightEye);
    lv_anim_set_values(&a, 247, 257);
    lv_anim_set_duration(&a, 300);
    lv_anim_set_path_cb(&a, lv_anim_path_ease_in_out);
    lv_anim_set_exec_cb(&a, _setEyeX);
    lv_anim_set_completed_cb(&a, _confusedRightDone);
    lv_anim_start(&a);
}

// X 坐标设置回调
static void _setEyeX(void* var, int32_t value) {
    lv_obj_set_x((lv_obj_t*)var, value);
}

// 左眼动画完成后，启动右眼（反方向）
static void _confusedLeftDone(lv_anim_t* a) {
    lv_anim_t a2;
    lv_anim_init(&a2);
    lv_anim_set_var(&a2, catFace._leftEye);
    lv_anim_set_values(&a2, 103, 113);  // 返回原位
    lv_anim_set_duration(&a2, 300);
    lv_anim_set_path_cb(&a2, lv_anim_path_ease_in_out);
    lv_anim_set_exec_cb(&a2, _setEyeX);
    lv_anim_start(&a2);
}

// 右眼动画完成后，恢复原位
static void _confusedRightDone(lv_anim_t* a) {
    lv_anim_t a2;
    lv_anim_init(&a2);
    lv_anim_set_var(&a2, catFace._rightEye);
    lv_anim_set_values(&a2, 257, 247);  // 返回原位
    lv_anim_set_duration(&a2, 300);
    lv_anim_set_path_cb(&a2, lv_anim_path_ease_in_out);
    lv_anim_set_exec_cb(&a2, _setEyeX);
    lv_anim_start(&a2);
}
```

## 3.5.4 后端端实现

### 步骤 1：添加情绪检测（`services/emotion.py`）

```python
# services/emotion.py

def analyze_emotion(text: str) -> str:
    """
    分析文本情绪
    Returns: neutral, happy, thinking, confused, angry
    """
    text_lower = text.lower()
    
    # Confused 检测：疑问句 ← 新增
    confused_patterns = ["吗", "呢", "?", "？", "什么", "为什么", "怎么了", "啥"]
    if any(p in text_lower for p in confused_patterns):
        return "confused"
    
    # Angry 检测
    angry_patterns = ["哼", "讨厌", "讨厌你", "不理你", "生气了"]
    if any(p in text_lower for p in angry_patterns):
        return "angry"
    
    # Happy 检测
    happy_patterns = ["!", "～", "~", "哈哈", "嘻嘻", "嘿嘿", "喵喵"]
    if any(p in text_lower for p in happy_patterns):
        return "happy"
    
    # Thinking 检测
    thinking_patterns = ["嗯", "呃", "这个", "让我想想", "也许", "可能"]
    if any(p in text_lower for p in thinking_patterns):
        return "thinking"
    
    return "neutral"
```

## 3.5.6 调试技巧

### 表情不切换？

**检查点：**
1. 串口日志是否有 `[CatFace] -> Confused`
2. 后端返回的 `emotion` 字段是否为 `confused`
3. `setExpression` 是否被调用

**调试代码：**
```cpp
// 在 cloud_client.cpp 中添加调试
if (strcmp(emotion, "confused") == 0) {
    Serial.println("[Cloud] 检测到 confused 情绪");
    catFace.setExpression(CAT_CONFUSED);
}
```

### 后端返回错误？

**检查点：**
1. 后端日志：`journalctl -u cybercat-backend -f`
2. emotion.py 是否正确检测
3. LLM 回复格式是否正确

**调试代码：**
```python
# main.py 中添加日志
@app.post("/chat")
async def chat(request: Request):
    # ...
    emo = emotion.analyze(reply)
    print(f"[Debug] 回复：{reply}, 情绪：{emo}")
    # ...
```

### 动画不流畅？

**检查点：**
1. LVGL 刷新率：`LV_DISP_DEF_REFR_PERIOD` 应为 16ms（60fps）
2. 动画时长：300ms → 500ms 更柔和
3. 缓动曲线：`ease_in_out` → `linear` 测试

**优化代码：**
```cpp
// 增加动画时长，使其更柔和
lv_anim_set_duration(&a, 500);  // 从 300ms 增加到 500ms

// 或更改缓动曲线
lv_anim_set_path_cb(&a, lv_anim_path_linear);  // 匀速
```

## 常见问题

**Q: 新表情编译报错？**  
A: 检查枚举值是否在 `CAT_EXPR_COUNT` 之前，数组大小是否匹配。

**Q: 后端情绪检测不准确？**  
A: 考虑用 LLM 分类，或增加更多关键词模式。

**Q: 摇头动画太机械？**  
A: 调整缓动曲线，增加随机性，如每次摇头幅度略有不同。
