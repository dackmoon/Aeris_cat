## 2.1.1 硬件架构

### 核心硬件：微雪 ESP32-S3-Touch-LCD-1.85C V2

本项目使用微雪一体化开发板，所有外设板载集成，无需接线。

**板载模块总览：**

```
┌─────────────────────────────────────────────────────────┐
│              ESP32-S3-Touch-LCD-1.85C V2                │
│                                                         │
│  ┌─────────────┐              ┌─────────────────────┐  │
│  │  ESP32-S3R8 │              │   1.85" 圆形屏幕     │  │
│  │  双核 240MHz │              │   ST77916 驱动      │  │
│  │  8MB PSRAM   │              │   360x360 分辨率    │  │
│  │  16MB Flash  │              │   262K 色           │  │
│  └─────────────┘              └────────────────────┘  │
│         │                                              │
│    ┌────┴─────────────────────────────────┐           │
│    │  板载外设（I2C + I2S + SPI）          │           │
│    ├──────────────────────────────────────┤           │
│    │  • CST816 触摸控制器 (I2C)            │           │
│    │  • ES7210 音频 ADC (I2S + I2C)        │           │
│    │  • ES8311 音频 DAC (I2S + I2C)        │           │
│    │  • QMI8658 陀螺仪 (I2C)               │           │
│    │  • PCF85063 RTC 时钟 (I2C)            │           │
│    │  • TCA9554 GPIO 扩展器 (I2C)          │           │
│    │  • SD 卡槽 (SPI)                      │           │
│    └──────────────────────────────────────┘           │
│                                                         │
│  [USB-C]  [电源开关]  [复位键]  [BOOT 键]                │
└─────────────────────────────────────────────────────────┘
```

### 硬件规格详解

| 模块 | 芯片/型号 | 接口 | 引脚 | 用途 |
|------|-----------|------|------|------|
| **主控** | ESP32-S3R8 | - | - | 双核 240MHz, 8MB PSRAM, 16MB Flash |
| **屏幕** | ST77916 | QSPI | GPIO46/45/42/41/40/21 | 1.85 寸圆形 360x360 |
| **触摸** | CST816 | I2C | GPIO11(SDA)/GPIO10(SCL) | 电容触摸，手势检测 |
| **音频 ADC** | ES7210 | I2S + I2C | I2S: GPIO2/48/38/39 | 双麦克风输入 |
| **音频 DAC** | ES8311 | I2S + I2C | I2S: GPIO2/48/38/47 | 喇叭输出 |
| **功放** | NS4150B | GPIO | GPIO15 | PA 控制（静音/使能）|
| **陀螺仪** | QMI8658 | I2C | GPIO10/11 | 6 轴 IMU（预留）|
| **RTC 时钟** | PCF85063 | I2C | GPIO10/11 | 实时时钟（预留）|
| **GPIO 扩展** | TCA9554 | I2C | GPIO10/11 | 控制 LCD_RST 等 |
| **SD 卡** | Micro SD | SPI | GPIO16/17/14/EXIO3 | 存储扩展（预留）|

### 共享总线架构

**I2S 音频总线（共享）：**
```
ESP32-S3 (I2S Master)
    │
    ├── MCLK → GPIO2  → ES7210 MCLK
    │                → ES8311 MCLK
    │
    ├── BCK  → GPIO48 → ES7210 BCK
    │                → ES8311 BCK
    │
    ├── LRCK → GPIO38 → ES7210 LRCK
    │                → ES8311 LRCK
    │
    ├── DIN  → GPIO39 → ES7210 DATA OUT (录音)
    │
    └── DOUT → GPIO47 → ES8311 DATA IN (播放)

注意：录音和播放不能同时进行（共享总线）
```

**I2C 设备地址：**
| 设备 | 7 位地址 | 用途 |
|------|---------|------|
| CST816 | 0x15 | 触摸控制器 |
| ES7210 | 0x40 | 音频 ADC |
| ES8311 | 0x18 | 音频 DAC |
| TCA9554 | 0x20 | GPIO 扩展器 |
| QMI8658 | 0x6B | 陀螺仪 |
| PCF85063 | 0x51 | RTC 时钟 |

### 电源架构

```
USB-C (5V) ──┬── ESP32-S3 电源管理 ──→ 3.3V 数字电路
             │                       ──→ 1.8V CPU 核心
             │
             ├── 屏幕背光 ──→ 5V boost
             │
             └── 音频功放 ──→ 5V AVDD

锂电池 (3.7V) ──→ 充放电管理 ──→ 系统供电
```

### FreeRTOS 任务架构

```
Core 0 (系统优先):
├── WiFi/BT 协议栈 (系统管理)
├── LVGL 任务 (prio 8, 16ms 间隔)
└── IDLE 监控任务

Core 1 (应用):
├── 主循环任务 (prio 5, 状态机)
├── 音频录制任务 (prio 10, I2S DMA)
├── 云端请求任务 (prio 5, HTTP/HTTPS)
└── 音频播放任务 (prio 10, I2S DMA)

任务通信方式：
- 状态标志：volatile 变量（简单状态）
- 队列：FreeRTOS Queue（音频数据、事件）
- 信号量：Semaphore（资源互斥）
```

### 服务配置

**systemd 服务配置：**
```ini
# /etc/systemd/system/cybercat-backend.service
[Unit]
Description=Cyber Cat Backend
After=network.target

User=root
```

## 常见问题

**Q: 为什么 ES7210 和 ES8311 共用 I2S 总线？**  
A: 节省 GPIO 引脚。ESP32-S3 的 I2S 外设支持全双工，但不能同时录音和播放（会回授）。

**Q: 云端 API 为什么选择 SiliconFlow？**  
A: SiliconFlow 提供统一的 API Key 和 OpenAI 兼容接口，STT+TTS 可以共用一个 Key，简化配置。

**Q: systemd 服务启动失败怎么办？**  
A: 用 `journalctl -u cybercat-backend -f` 查看日志，常见问题：端口占用、.env 配置错误、依赖未安装。
