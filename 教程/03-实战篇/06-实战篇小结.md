```cpp
// 统一入口函数

    // 1. 取消现有动画

    }
```

### 2. 情绪检测规则引擎

```python
# 基础版：规则匹配
def analyze_emotion(text: str) -> str:
    text_lower = text.lower()
    
    confused_patterns = ["吗", "呢", "?", "？", "什么", "为什么"]
    if any(p in text_lower for p in confused_patterns):
        return "confused"
    
    angry_patterns = ["哼", "讨厌", "讨厌你"]
    if any(p in text_lower for p in angry_patterns):
        return "angry"
    
    return "neutral"

# 进阶版：LLM 分类（留作扩展）
async def analyze_emotion_llm(text: str) -> str:
    prompt = f"分析以下文本的情绪，返回：neutral/happy/angry/confused/thinking\n\n文本：{text}"
    response = await llm_api.complete(prompt)
    return response.strip()
```

### 3. 设备会话隔离

```python
# 后端：按设备 ID 隔离
@app.post("/chat")
async def chat(
    request: Request,
    x_device_id: str = Header(None)
):
    # 会话 ID 生成
    if x_device_id:
        session_id = f"device-{x_device_id}"
    else:
        session_id = "default"
    
    # 记忆隔离
    memory_summary = repository.get_memory_summary(session_id)
    session_history = repository.get_session_history(session_id)
    
    # LLM 注入记忆
    reply = await llm.chat_completion(
        transcript,
        memory_summary=memory_summary,
        session_history=session_history
    )
    
    # 保存回该设备的记忆
    repository.save_interaction(session_id, transcript, reply)
```

**关键设计：**
- 设备 ID 作为隔离维度
- 每个设备独立的记忆摘要
- 会话历史按设备分表

```cpp
    }
}
```

### 5. 语音命令处理流程

```cpp
// 初始化
void voiceCommandInit() {
    esp_sr_config_t config = ESP_SR_DEFAULT_CONFIG();
    config.afe_mode = SR_LOW_ENERGY;
    sr_handle = esp_sr_create(&config);
    
    // 添加命令词
    esp_sr_add_command(sr_handle, "开灯");
    esp_sr_add_command(sr_handle, "关灯");
    // ...
}

// 循环处理
VoiceCommand voiceCommandLoop() {
    if (esp_sr_is_done(sr_handle)) {
        char* result = esp_sr_get_result(sr_handle);
        float confidence = esp_sr_get_confidence(sr_handle);
        
        // 置信度过滤
        if (confidence > 0.8f) {
            // 匹配命令
            if (strcmp(result, "开灯") == 0) {
                return CMD_LIGHT_ON;
            }
            // ...
        }
        
        free(result);
    }
    return CMD_NONE;
}
```

## 3.6.7 常见问题答疑

### Q1: 新增表情后编译失败？

**A:** 检查以下几点：
- 枚举值是否在 `CAT_EXPR_COUNT` 之前
- `EXPRESSION_PARAMS` 数组大小是否匹配（应该是 7 个元素）
- `catExprName` 函数是否添加了新名称
- `setExpression` switch 语句是否有对应的 case

### Q2: 后端情绪检测不准确？

**A:** 三种解决方案：
1. 增加关键词模式（覆盖更多表达）
2. 用 LLM 进行分类（更准确但慢）
3. 混合方案：规则快速过滤 + LLM 处理模糊情况

### Q3: 设备重连后记忆丢失？

**A:** 检查：
- session_id 生成逻辑是否一致
- 数据库中 `interactions` 表的 `session_id` 字段是否正确
- `get_memory_summary` 查询条件是否包含该 session_id

### Q4: 离线模式耗电快？

**A:** 优化方案：
- 启用 ESP32 轻睡眠（`esp_light_sleep_start`）
- 降低轮询频率（触摸检测从 10ms 改为 100ms）
- 关闭不必要的 peripherals（如 I2S 待机关闭）

### Q5: 语音命令误识别？

**A:** 调整策略：
- 提高置信度阈值（0.8 → 0.9）
- 添加唤醒词（"小喵小喵"）
- 启用 AFE 降噪（高性能模式）
