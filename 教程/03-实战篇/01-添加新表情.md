## 3.1.2 步骤 1：定义枚举值

### 编辑 `src/cat_face.h`

在 `CAT_EXPR_COUNT` 之前添加新的枚举值：

```cpp
// cat_face.h

enum CatExpression {
    CAT_NEUTRAL = 0,
    CAT_HAPPY,
    CAT_LISTENING,
    CAT_THINKING,
    CAT_SLEEPY,
    CAT_TALKING,
    CAT_ANGRY,              // ← 新增：生气
    CAT_EXPR_COUNT          // 保持这个在最后（自动 = 7）
};
```

**为什么这样做：**
- 枚举值从 0 开始递增
- `CAT_EXPR_COUNT` 用于数组大小和边界检查
- 新增的必须放在 `COUNT` 之前

### 添加表情参数

在 `EXPRESSION_PARAMS` 数组中添加生气表情的参数：

```cpp
// cat_face.cpp

// 表情参数表（ROM 中存储）
const EyeParams EXPRESSION_PARAMS[] = {
    // CAT_NEUTRAL: 两个大白圆
    {.w = 95, .h = 95, .rot = 0,    .yOffset = 0,   .fixedLook = false},
    
    // CAT_HAPPY: 柔和眯眼，Y 上移
    {.w = 95, .h = 55, .rot = 0,    .yOffset = -5,  .fixedLook = true},
    
    // CAT_LISTENING: 放大，略不对称
    {.w = 118,.h = 118, .rot = 0,   .yOffset = 0,   .fixedLook = true},
    
    // CAT_THINKING: 微眯外偏
    {.w = 88, .h = 78,  .rot = 50,  .yOffset = 0,   .fixedLook = false},
    
    // CAT_SLEEPY: 极细线
    {.w = 80, .h = 8,   .rot = 0,   .yOffset = 0,   .fixedLook = true},
    
    // CAT_TALKING: 圆眼（律动由动画控制）
    {.w = 95, .h = 95,  .rot = 0,   .yOffset = 0,   .fixedLook = true},
    
    // CAT_ANGRY: 倒三角，内斜 ← 新增
    {.w = 95, .h = 70,  .rot = -150,.yOffset = 0,   .fixedLook = true},
    // 注意：右眼的旋转会在 setExpression 中取反
};
```

**眼睛参数设计思路：**

| 表情 | 宽度 | 高度 | 旋转 | 效果 |
|------|------|------|------|------|
| Neutral | 95 | 95 | 0° | 正圆 |
| Happy | 95 | 55 | 0° | 压扁（眯眼）|
| **Angry** | **95** | **70** | **±15°** | **压扁 + 内斜（愤怒）** |

## 3.1.3 步骤 2：实现表情渲染

### 实现生气表情逻辑

在 `setExpression` 的 switch 语句中添加 case：

```cpp
void CatFace::setExpression(CatExpression expr) {
    if (_cur == expr) return;
    _cur = expr;
    _exprStartTime = millis();
    
    // 取消所有现有动画
    lv_anim_delete(_leftEye, NULL);
    lv_anim_delete(_rightEye, NULL);
    
    // 获取目标参数
    const EyeParams& target = EXPRESSION_PARAMS[expr];
    
    switch (expr) {
        case CAT_NEUTRAL:
            _setNeutral();
            break;
        case CAT_HAPPY:
            _setHappy();
            break;
        case CAT_LISTENING:
            _setListening();
            break;
        case CAT_THINKING:
            _setThinking();
            break;
        case CAT_SLEEPY:
            _setSleepy();
            break;
        case CAT_TALKING:
            _startTalkingAnim();
            break;
        case CAT_ANGRY:              // ← 新增
            _setAngry();
            break;
    }
    
    Serial.printf("[CatFace] -> %s\n", catExprName(expr));
}
```

### 实现 `_setAngry()` 函数

```cpp
// cat_face.cpp

void CatFace::_setAngry() {
    // 生气：眼睛变成倒三角，向内倾斜
    // 左眼：向右下倾斜 -15 度（LVGL 逆时针为正，所以是负值）
    // 右眼：向左下倾斜 +15 度
    
    // 获取目标参数
    const EyeParams& target = EXPRESSION_PARAMS[CAT_ANGRY];
    
    // 左眼动画
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, _leftEye);
    lv_anim_set_values(&a, _currentEye.w, target.w);
    lv_anim_set_duration(&a, 350);
    lv_anim_set_path_cb(&a, lv_anim_path_ease_in_out);
    lv_anim_set_exec_cb(&a, _setEyeWidth);
    lv_anim_start(&a);
    
    lv_anim_init(&a);
    lv_anim_set_var(&a, _leftEye);
    lv_anim_set_values(&a, _currentEye.h, target.h);
    lv_anim_set_duration(&a, 350);
    lv_anim_set_exec_cb(&a, _setEyeHeight);
    lv_anim_start(&a);
    
    lv_anim_init(&a);
    lv_anim_set_var(&a, _leftEye);
    lv_anim_set_values(&a, _currentEye.rot, target.rot);  // -150 (即 -15°)
    lv_anim_set_duration(&a, 350);
    lv_anim_set_exec_cb(&a, _setEyeRotation);
    lv_anim_start(&a);
    
    // 右眼动画（旋转角度取反）
    lv_anim_init(&a);
    lv_anim_set_var(&a, _rightEye);
    lv_anim_set_values(&a, _currentEye.w, target.w);
    lv_anim_set_duration(&a, 350);
    lv_anim_set_exec_cb(&a, _setEyeWidth);
    lv_anim_start(&a);
    
    lv_anim_init(&a);
    lv_anim_set_var(&a, _rightEye);
    lv_anim_set_values(&a, _currentEye.h, target.h);
    lv_anim_set_duration(&a, 350);
    lv_anim_set_exec_cb(&a, _setEyeHeight);
    lv_anim_start(&a);
    
    lv_anim_init(&a);
    lv_anim_set_var(&a, _rightEye);
    lv_anim_set_values(&a, _currentEye.rot, -target.rot);  // +150 (即 +15°)
    lv_anim_set_duration(&a, 350);
    lv_anim_set_exec_cb(&a, _setEyeRotation);
    lv_anim_start(&a);
    
    // 设置生气计时器：2 秒后恢复平静
    _angryTimer = millis() + 2000;
    _angryTimerActive = true;
}
```

## 3.1.4 步骤 3：后端情绪检测

### 编辑 `services/emotion.py`

添加生气情绪检测逻辑：

```python
# services/emotion.py

def analyze_emotion(text: str) -> str:
    """
    分析文本情绪
    Returns: neutral, happy, thinking, angry, talking
    """
    text_lower = text.lower()
    
    # Angry 检测：生气词汇
    angry_patterns = [
        "哼", "讨厌", "讨厌你", "不理你", "生气了", 
        "喵！", "！", "坏蛋", "气死我了"
    ]
    if any(p in text_lower for p in angry_patterns):
        return "angry"
    
    # Happy 检测
    happy_patterns = ["!", "～", "~", "哈哈", "嘻嘻", "嘿嘿", "喵喵", "喵~"]
    if any(p in text_lower for p in happy_patterns):
        return "happy"
    
    # Thinking 检测
    thinking_patterns = ["嗯", "呃", "这个", "让我想想", "也许", "可能", "大概"]
    if any(p in text_lower for p in thinking_patterns):
        return "thinking"
    
    return "neutral"
```

## 常见问题

**Q: 表情切换不流畅？**  
A: 检查 LVGL 刷新率（`LV_DISP_DEF_REFR_PERIOD` 应为 16ms），确保动画时长足够。

**Q: 右眼旋转方向不对？**  
A: 右眼的旋转角度应取反（`-target.rot`），因为 LVGL 旋转是相对于对象中心的。

**Q: 计时器不触发恢复？**  
A: 确保 `update()` 在主循环中被持续调用，且 `_angryTimerActive` 标志正确设置。
