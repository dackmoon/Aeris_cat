## 1.6.1 ESP32-S3 硬件架构

### ESP32-S3 概述

ESP32-S3 是乐鑫 2021 年推出的双核 Wi-Fi + 蓝牙 SoC，相比经典 ESP32 有更大内存和更好的 AI 加速能力。

**主要规格：**

| 特性 | 规格 |
|------|------|
| CPU | 双核 Xtensa LX7，最高 240MHz |
| SRAM | 512KB（内部高速 RAM）|
| PSRAM | 最高 8MB（外部 RAM，本项目用 8MB）|
| Flash | 最高 32MB（本项目用 16MB）|
| Wi-Fi | 802.11 b/g/n (2.4 GHz) |
| Bluetooth | Bluetooth 5 (LE) |
| GPIO | 45 个可编程引脚 |
| 封装 | QFN 6x6mm |

### 内存映射

```
ESP32-S3 内存布局：

┌─────────────────────────────────┐
│   Flash (16MB)                  │  存储程序代码、常量、SPIFFS
│   0x00000000 - 0x00FFFFFF       │
├─────────────────────────────────┤
│   PSRAM (8MB)                   │  大容量外部 RAM，速度较慢
│   0x3C000000 - 0x3C7FFFFF       │
├─────────────────────────────────┤
│   Internal SRAM (512KB)         │  高速内部 RAM
│   0x30000000 - 0x3007FFFF       │
│   - CPU Cache                   │
│   - DMA 缓冲区                   │
│   - 堆栈                        │
└─────────────────────────────────┘
```

### 本项目使用的板子

**微雪 ESP32-S3-Touch-LCD-1.85C V2：**

- **型号**：ESP32-S3R8（8MB PSRAM 版本）
- **屏幕**：ST77916 驱动，360x360 圆形 IPS
- **触摸**：CST816 电容触摸
- **音频**：ES7210 ADC + ES8311 DAC
- **其他**：QMI8658 陀螺仪、PCF85063 RTC、TCA9554 GPIO 扩展器

## 1.6.2 GPIO 与外设

### GPIO 引脚编号

ESP32-S3 有 45 个 GPIO 引脚，编号从 GPIO0 到 GPIO48（部分引脚不存在）。

**重要引脚功能：**

| GPIO | 功能 | 本项目用途 | 注意事项 |
|------|------|-----------|---------|
| GPIO0 | BOOT | 启动模式选择 | 低电平启动下载模式 |
| GPIO1 | - | 悬空 | - |
| GPIO2 | MCLK | I2S 主时钟 | 输出时钟信号 |
| GPIO3-7 | - | 可用 | - |
| GPIO8-11 | I2C/UART | 触摸 I2C | GPIO11=SDA, GPIO10=SCL |
| GPIO12-17 | SPI/GPIO | SD 卡/可用 | - |
| GPIO18 | TE | 屏幕 TE 信号 | - |
| GPIO19-20 | USB | USB D+/D- | - |
| GPIO21 | CS | 屏幕片选 | - |
| GPIO26-32 | - | 可用 | - |
| GPIO33-38 | I2S/BT | I2S 接口 | GPIO38=LRCK |
| GPIO39-42 | I2S/SPI | I2S 数据 | GPIO39=DIN, GPIO47=DOUT |
| GPIO45-46 | SPI | 屏幕 QSPI | - |
| GPIO47-48 | I2S/SPI | I2S 时钟 | - |

### GPIO 模式配置

```cpp
// Arduino 风格
void setup() {
    // 输出模式
    pinMode(GPIO2, OUTPUT);
    digitalWrite(GPIO2, HIGH);
    
    // 输入模式
    pinMode(GPIO3, INPUT);
    int value = digitalRead(GPIO3);
    
    // 输入带上拉
    pinMode(GPIO4, INPUT_PULLUP);
    
    // 模拟输入（仅部分引脚支持）
    pinMode(GPIO1, ANALOG);
    int analogValue = analogRead(GPIO1);
}
```

**ESP-IDF 风格：**

```cpp
#include "driver/gpio.h"

// 配置输出
gpio_config_t io_conf = {};
io_conf.mode = GPIO_MODE_OUTPUT;
io_conf.pin_bit_mask = (1ULL << GPIO2);
gpio_config(&io_conf);

// 设置高低电平
gpio_set_level(GPIO2, 1);  // 高电平
gpio_set_level(GPIO2, 0);  // 低电平

// 读取电平
int level = gpio_get_level(GPIO3);
```

### PWM（脉冲宽度调制）

```cpp
#include <ledc.h>

// 配置 PWM
ledcAttach(GPIO5, 1000, 10);  // GPIO5, 1kHz, 10bit 分辨率

// 设置占空比（0-1023 for 10bit）
ledcWrite(GPIO5, 512);  // 50% 占空比

// 控制 LED 亮度
ledcWrite(GPIO5, 0);    // 最暗
ledcWrite(GPIO5, 1023); // 最亮
```

**项目应用 - 屏幕背光控制：**

```cpp
// 初始化背光 PWM
void initBacklight() {
    ledcAttach(GPIO5, 20000, 10);  // 20kHz 避免 audible noise
    Set_Backlight(50);  // 50% 亮度
}

// 设置背光亮度（0-100）
void Set_Backlight(uint8_t percent) {
    if (percent > 100) percent = 100;
    uint32_t duty = (percent * 1023) / 100;
    ledcWrite(GPIO5, duty);
}
```

## 1.6.3 I2C 总线协议

### I2C 基础

**I2C 是什么？** I2C（Inter-Integrated Circuit）是一种两线制串行通信协议。

**信号线：**
- **SDA**（Serial Data）：数据线，双向
- **SCL**（Serial Clock）：时钟线，由主设备产生

**特点：**
- 半双工通信
- 支持多主多从
- 每个从设备有唯一 7 位地址
- 标准速度：100kHz，快速：400kHz

**本项目 I2C 设备地址：**

| 设备 | 地址 | 用途 |
|------|------|------|
| CST816 | 0x15 | 触摸控制器 |
| ES7210 | 0x40 | 音频 ADC |
| ES8311 | 0x18 | 音频 DAC |
| TCA9554 | 0x20 | GPIO 扩展器 |
| QMI8658 | 0x6B | 陀螺仪 |

### Wire 库使用

```cpp
#include <Wire.h>

void setup() {
    // 初始化 I2C（默认 GPIO8=SDA, GPIO9=SCL）
    Wire.begin();
    
    // 或指定引脚（本项目）
    Wire.begin(GPIO11, GPIO10);  // SDA=GPIO11, SCL=GPIO10
}

// 扫描 I2C 设备
void scanI2C() {
    Serial.println("扫描 I2C 设备...");
    for (uint8_t addr = 1; addr < 127; addr++) {
        Wire.beginTransmission(addr);
        if (Wire.endTransmission() == 0) {
            Serial.printf("找到设备：0x%02X\n", addr);
        }
    }
}
```

### 读写设备寄存器

```cpp
// 写入寄存器
void writeRegister(uint8_t devAddr, uint8_t regAddr, uint8_t value) {
    Wire.beginTransmission(devAddr);
    Wire.write(regAddr);
    Wire.write(value);
    Wire.endTransmission();
}

// 读取寄存器
uint8_t readRegister(uint8_t devAddr, uint8_t regAddr) {
    Wire.beginTransmission(devAddr);
    Wire.write(regAddr);
    Wire.endTransmission();
    
    Wire.requestFrom(devAddr, 1);
    return Wire.read();
}

// 读取多个字节
void readRegisters(uint8_t devAddr, uint8_t regAddr, uint8_t* buffer, uint8_t length) {
    Wire.beginTransmission(devAddr);
    Wire.write(regAddr);
    Wire.endTransmission();
    
    Wire.requestFrom(devAddr, length);
    for (int i = 0; i < length; i++) {
        buffer[i] = Wire.read();
    }
}
```

**项目应用 - ES7210 初始化：**

```cpp
// ES7210 寄存器配置表
const uint8_t es7210Init[][2] = {
    {0x00, 0x41},  // 软件复位
    {0x01, 0x41},  // 时钟配置
    {0x04, 0x1C},  // ADC 配置
    {0x05, 0x20},  // 增益设置 24dB
    {0xFF, 0xFF}   // 结束标记
};

void es7210Init() {
    Wire.beginTransmission(0x40);  // ES7210 地址
    for (int i = 0; es7210Init[i][0] != 0xFF; i++) {
        Wire.write(es7210Init[i][0]);
        Wire.write(es7210Init[i][1]);
    }
    Wire.endTransmission();
}
```

## 1.6.4 I2S 音频接口

### I2S 基础

**I2S 是什么？** I2S（Inter-IC Sound）是飞利浦制定的数字音频传输标准。

**信号线：**
- **MCLK**（Master Clock）：主时钟，通常是采样率的 256 倍
- **BCK**（Bit Clock）：位时钟
- **LRCK/WS**（Word Select）：左右声道选择
- **SD**（Serial Data）：串行数据

**本项目 I2S 配置：**

| 信号 | GPIO | 说明 |
|------|------|------|
| MCLK | GPIO2 | 16kHz × 256 = 4.096MHz |
| BCK | GPIO48 | 位时钟 |
| LRCK | GPIO38 | 左右声道选择 |
| DIN | GPIO39 | 麦克风输入（录音）|
| DOUT | GPIO47 | 喇叭输出（播放）|

### I2S 驱动使用（遗留 API）

```cpp
#include <driver/i2s.h>

// I2S 配置
i2s_config_t i2sConfig = {
    .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_RX | I2S_MODE_TX),
    .sample_rate = 16000,
    .bits_per_sample = I2S_BITS_PER_SAMPLE_16BIT,
    .channel_format = I2S_CHANNEL_FMT_ONLY_LEFT,
    .communication_format = I2S_COMM_FORMAT_STAND_I2S,
    .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
    .dma_buf_count = 4,
    .dma_buf_len = 256,
    .use_apll = false,
    .tx_desc_auto_clear = true,
    .fixed_mclk = 0
};

// 引脚配置
i2s_pin_config_t pinConfig = {
    .mclk_io_num = GPIO2,
    .bck_io_num = GPIO48,
    .ws_io_num = GPIO38,
    .data_out_num = GPIO47,
    .data_in_num = GPIO39
};

// 初始化
void audioInit() {
    i2s_driver_install(I2S_NUM_0, &i2sConfig, 0, NULL);
    i2s_set_pin(I2S_NUM_0, &pinConfig);
}

// 录音
size_t i2s_read_bytes(uint8_t* buffer, size_t bytes) {
    size_t bytesRead;
    i2s_read(I2S_NUM_0, buffer, bytes, &bytesRead, portMAX_DELAY);
    return bytesRead;
}

// 播放
size_t i2s_write_bytes(const uint8_t* buffer, size_t bytes) {
    size_t bytesWritten;
    i2s_write(I2S_NUM_0, buffer, bytes, &bytesWritten, portMAX_DELAY);
    return bytesWritten;
}
```

### 音频数据格式

**16-bit 立体声格式：**

```
一个音频帧（16-bit stereo）：
[左声道 L15...L0] [右声道 R15...R0]

本项目麦克风是单声道，只使用左声道数据
```

**单声道转立体声：**

```cpp
void monoToStereo(int16_t* mono, int16_t* stereo, size_t samples) {
    for (size_t i = 0; i < samples; i++) {
        stereo[i * 2] = mono[i];      // 左声道
        stereo[i * 2 + 1] = mono[i];  // 右声道
    }
}
```

## 1.6.5 FreeRTOS 任务调度

### FreeRTOS 基础

ESP32 运行 FreeRTOS 实时操作系统，支持多任务并发。

**关键概念：**

| 术语 | 说明 |
|------|------|
| Task（任务） | 独立执行的函数 |
| Priority（优先级） | 数字越大优先级越高（0-24）|
| Stack（栈） | 任务私有内存空间 |
| Queue（队列） | 任务间通信机制 |
| Core（核心） | ESP32-S3 有 2 个 CPU 核心 |

### 任务创建

```cpp
#include <freertos/FreeRTOS.h>
#include <freertos/task.h>

// 任务函数
void taskFunction(void* parameter) {
    while (true) {
        // 任务逻辑
        Serial.println("Task running");
        
        // 延迟（让出 CPU）
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

// 创建任务
TaskHandle_t taskHandle;
xTaskCreate(
    taskFunction,           // 任务函数
    "MyTask",               // 任务名称
    4096,                   // 栈大小（字节）
    NULL,                   // 参数
    5,                      // 优先级
    &taskHandle             // 任务句柄
);
```

### 核心绑定

```cpp
// 绑定到特定核心
xTaskCreatePinnedToCore(
    taskFunction,
    "Core1Task",
    4096,
    NULL,
    5,
    &taskHandle,
    1           // Core 1
);

// ESP32-S3 核心分配：
// Core 0: WiFi、Bluetooth、中断处理
// Core 1: 应用任务
// 建议：将耗时的应用任务放在 Core 1
```

### 任务优先级

```cpp
// 优先级范围：0-24（ESP32）
// 建议分配：
// 5-8:  普通应用任务
// 10-15: 实时任务（音频、显示）
// 18-24: 高优先级任务（中断处理）

// 获取当前优先级
uxBasePriority = uxTaskPriorityGet(taskHandle);

// 修改优先级
vTaskPrioritySet(taskHandle, newPriority);

// 删除任务
vTaskDelete(taskHandle);
```

### 任务同步

**使用信号量：**

```cpp
#include <semphr.h>

// 创建二值信号量
SemaphoreHandle_t xSemaphore = xSemaphoreCreateBinary();

// 任务 A：释放信号量
void taskA(void* parameter) {
    while (true) {
        // 做某事...
        xSemaphoreGive(xSemaphore);
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

// 任务 B：等待信号量
void taskB(void* parameter) {
    while (true) {
        if (xSemaphoreTake(xSemaphore, portMAX_DELAY)) {
            // 收到信号，执行操作
            Serial.println("Received signal");
        }
    }
}
```

**使用队列：**

```cpp
#include <freertos/queue.h>

// 创建队列（存储 10 个整数）
QueueHandle_t xQueue = xQueueCreate(10, sizeof(int));

// 发送到队列
int value = 42;
xQueueSend(xQueue, &value, portMAX_DELAY);

// 从队列接收
int receivedValue;
if (xQueueReceive(xQueue, &receivedValue, portMAX_DELAY)) {
    Serial.printf("Received: %d\n", receivedValue);
}
```

## 常见问题

**Q: GPIO 输出没有反应？**  
A: 检查引脚是否支持输出功能，某些引脚是输入专用（如 GPIO34-39）。

**Q: I2C 扫描不到设备？**  
A: 检查接线（SDA/SCL 是否接反）、上拉电阻、设备供电。

**Q: 任务创建后系统重启？**  
A: 可能是栈空间不足，增加栈大小（如 4096 → 8192）。

**Q: 音频有杂音？**  
A: 检查 I2S 时钟配置、接地、音频线屏蔽。
