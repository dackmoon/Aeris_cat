## 1.10.1 数字音频基础

### 声音是什么？

**声音**是机械波在介质（空气、水、固体）中传播的现象。

**声音的三要素：**
| 要素 | 物理量 | 主观感受 |
|------|--------|----------|
| 音调 | 频率 (Hz) | 高/低 |
| 响度 | 振幅 | 大/小 |
| 音色 | 波形 | 不同乐器的区别 |

**人耳可听范围：** 20Hz - 20kHz

### 模拟信号 vs 数字信号

```
模拟音频：连续变化的电压波形
     /\      /\
    /  \    /  \
---/    \__/    \___

数字音频：离散的采样点
     •       •
    / \     / \
---•   •---•   •---
```

**数字化过程：**
1. **采样**：在时间轴上离散化
2. **量化**：在幅度轴上离散化
3. **编码**：转换为二进制数字

### 音频链路

```
声源 → 麦克风 → 前置放大 → ADC → 数字处理 → DAC → 功放 → 喇叭 → 声音

本项目链路：
人声 → ES7210 ADC → ESP32 I2S → WiFi → 后端 → TTS → ESP32 I2S → ES8311 DAC → 喇叭
```

## 1.10.2 采样率与位深

### 采样率（Sample Rate）

**采样率**：每秒采集的样本数，单位 Hz。

**奈奎斯特 - 香农采样定理：**
> 采样频率必须大于信号最高频率的 **2 倍**，才能无失真地还原信号。

```
人耳上限：20kHz
→ 最低采样率：40kHz
→ CD 标准：44.1kHz（留有余量）

语音频率范围：300Hz - 3.4kHz
→ 电话质量：8kHz
→ 本项目：16kHz（语音识别友好）
```

**常见采样率：**
| 采样率 | 用途 |
|--------|------|
| 8kHz | 电话语音 |
| 16kHz | 语音识别、对讲 |
| 44.1kHz | CD 音质 |
| 48kHz | 专业音频、视频 |
| 96kHz | 高解析音频 |

### 位深（Bit Depth）

**位深**：每个样本用多少位表示。

**动态范围计算公式：**
```
动态范围 (dB) ≈ 6.02 × 位深 + 1.76

16-bit: 6.02 × 16 + 1.76 ≈ 98 dB
24-bit: 6.02 × 24 + 1.76 ≈ 146 dB
```

**常见位深：**
| 位深 | 量化级别 | 用途 |
|------|---------|------|
| 8-bit | 256 级 | 对讲机、早期游戏 |
| 16-bit | 65,536 级 | CD、本项目 |
| 24-bit | 16,777,216 级 | 专业录音 |
| 32-bit float | 无限动态 | 后期制作 |

### 比特率（Bit Rate）

**比特率**：每秒传输的数据量。

```
比特率 = 采样率 × 位深 × 声道数

本项目（16kHz, 16-bit, 单声道）：
比特率 = 16000 × 16 × 1 = 256,000 bps = 256 kbps

CD 音质（44.1kHz, 16-bit, 立体声）：
比特率 = 44100 × 16 × 2 = 1,411,200 bps ≈ 1.4 Mbps
```

### 音频数据量计算

```
文件大小 = 比特率 × 时长 / 8 (字节)

本项目录制 10 秒语音：
256 kbps × 10s / 8 = 320 KB = 0.32 MB

CD 音质 1 分钟：
1.4 Mbps × 60s / 8 = 10.5 MB
```

## 1.10.3 音频编解码器

### 编解码器是什么？

**Codec**（Coder-Decoder）：编码和解解码音频数据的算法或设备。

**分类：**
| 类型 | 特点 | 示例 |
|------|------|------|
| 无损压缩 | 可完全还原 | FLAC, ALAC, WAV |
| 有损压缩 | 丢弃部分数据 | MP3, AAC, Opus |
|  uncompressed | 未压缩 | PCM, WAV |

### 本项目音频芯片

**ES7210（ADC - 音频模数转换器）：**
- 立体声 ADC
- 采样率：8kHz - 96kHz
- 位深：16/24/32-bit
- 信噪比：105dB
- 内置麦克风偏置和前置放大

**ES8311（DAC - 音频数模转换器）：**
- 立体声 DAC
- 采样率：8kHz - 96kHz
- 位深：16/24/32-bit
- 信噪比：100dB
- 内置耳机放大器

### I2S 音频接口

**I2S 信号线：**
```
MCLK (Master Clock): 主时钟，通常为采样率的 256 倍
BCK  (Bit Clock):    位时钟，采样率 × 位深
LRCK (Left/Right Clock): 左右声道选择
SD   (Serial Data):  串行数据

本项目配置（16kHz, 16-bit）：
MCLK = 16000 × 256 = 4.096 MHz
BCK  = 16000 × 16 = 256 kHz
LRCK = 16000 Hz
```

**I2S 数据格式：**
```
立体声 I2S 数据流：
LRCK 低电平：左声道数据
LRCK 高电平：右声道数据

每个声道 16 位：
[B15 B14 ... B1 B0]

本项目麦克风是单声道，只使用左声道
```

## 1.10.4 VAD 语音活动检测

### VAD 是什么？

**VAD**（Voice Activity Detection）：检测音频中是否有人声的技术。

**用途：**
- 自动开始/停止录音
- 节省带宽和存储
- 提高语音识别准确率

### VAD 实现方法

**方法 1：能量检测（本项目使用）**

```cpp
// 计算 RMS（均方根）能量
float calculateRMS(int16_t* samples, int count) {
    float sum = 0;
    for (int i = 0; i < count; i++) {
        sum += samples[i] * samples[i];
    }
    return sqrt(sum / count);
}

// VAD 判断
bool isSpeechDetected(float rms) {
    const float THRESHOLD = 400;  // 能量阈值
    return rms > THRESHOLD;
}
```

**方法 2：过零率检测**

```cpp
// 计算过零率
int calculateZeroCrossingRate(int16_t* samples, int count) {
    int crossings = 0;
    for (int i = 1; i < count; i++) {
        if ((samples[i] >= 0 && samples[i-1] < 0) ||
            (samples[i] < 0 && samples[i-1] >= 0)) {
            crossings++;
        }
    }
    return crossings;
}

// 语音的过零率通常较低（<100 次/秒）
// 噪声的过零率通常较高
```

**方法 3：机器学习 VAD**

- WebRTC VAD（开源，准确率高）
- Silero VAD（深度学习，精度最高）
- 本项目使用简单的能量检测（资源受限）

### 项目中的 VAD 实现

```cpp
// audio_input.h
#ifndef __AUDIO_INPUT_H__
#define __AUDIO_INPUT_H__

#include <Arduino.h>

// VAD 参数配置
#define VAD_RMS_THRESHOLD 400      // 能量阈值
#define VAD_SILENCE_MS 2000        // 静音 2 秒自动停止
#define VAD_MIN_SPEECH_MS 300      // 最短语音 300ms
#define AUDIO_MAX_SECONDS 30       // 最长录音 30 秒

class AudioInput {
private:
    int16_t* _buffer;
    size_t _bufferSize;
    size_t _writeIndex;
    
    uint32_t _speechStartMs;
    uint32_t _silenceStartMs;
    bool _isSpeechActive;
    
    float _calculateRMS(int16_t* samples, size_t count);
    
public:
    AudioInput(size_t bufferSize);
    ~AudioInput();
    
    void begin();
    size_t process(int16_t* samples, size_t count);
    bool isRecording();
    void stop();
};

#endif
```

```cpp
// audio_input.cpp
#include "audio_input.h"
#include <math.h>

AudioInput::AudioInput(size_t bufferSize) 
    : _bufferSize(bufferSize), _writeIndex(0),
      _speechStartMs(0), _silenceStartMs(0), 
      _isSpeechActive(false) {
    // 分配 PSRAM 缓冲区（30 秒 @16kHz 16-bit = 960KB）
    _buffer = (int16_t*)ps_malloc(bufferSize * sizeof(int16_t));
}

AudioInput::~AudioInput() {
    free(_buffer);
}

void AudioInput::begin() {
    // I2S 已在外部初始化
}

float AudioInput::_calculateRMS(int16_t* samples, size_t count) {
    float sum = 0;
    for (size_t i = 0; i < count; i++) {
        sum += samples[i] * samples[i];
    }
    return sqrt(sum / count);
}

size_t AudioInput::process(int16_t* samples, size_t count) {
    uint32_t now = millis();
    float rms = _calculateRMS(samples, count);
    
    if (!_isSpeechActive) {
        // 检测语音开始
        if (rms > VAD_RMS_THRESHOLD) {
            _isSpeechActive = true;
            _speechStartMs = now;
            _silenceStartMs = 0;
            Serial.println("[VAD] 语音开始");
        }
    } else {
        // 录音中
        if (rms < VAD_RMS_THRESHOLD) {
            // 低于阈值，开始计时静音
            if (_silenceStartMs == 0) {
                _silenceStartMs = now;
            } else if (now - _silenceStartMs > VAD_SILENCE_MS) {
                // 静音超时，停止录音
                _isSpeechActive = false;
                Serial.println("[VAD] 语音结束（静音超时）");
                return _writeIndex;  // 返回录音长度
            }
        } else {
            // 有声音，重置静音计时
            _silenceStartMs = 0;
        }
        
        // 检查最长录音时间
        if (now - _speechStartMs > AUDIO_MAX_SECONDS * 1000) {
            _isSpeechActive = false;
            Serial.println("[VAD] 语音结束（超时）");
            return _writeIndex;
        }
        
        // 将样本复制到缓冲区
        size_t copyCount = min(count, _bufferSize - _writeIndex);
        memcpy(_buffer + _writeIndex, samples, copyCount * sizeof(int16_t));
        _writeIndex += copyCount;
        
        // 缓冲区满
        if (_writeIndex >= _bufferSize) {
            _isSpeechActive = false;
            Serial.println("[VAD] 缓冲区满");
            return _writeIndex;
        }
    }
    
    return 0;  // 录音未结束
}

bool AudioInput::isRecording() {
    return _isSpeechActive;
}

void AudioInput::stop() {
    _isSpeechActive = false;
}
```

### VAD 调试技巧

```cpp
// 串口打印 VAD 状态
void debugVAD(float rms, bool isSpeech) {
    static uint32_t lastPrint = 0;
    uint32_t now = millis();
    
    if (now - lastPrint > 100) {  // 每 100ms 打印一次
        Serial.printf("[VAD] RMS=%.1f Speech=%d\n", rms, isSpeech ? 1 : 0);
        lastPrint = now;
    }
}
```

### 高级 VAD 特性

**双麦克风降噪（未来扩展）：**

```cpp
// 使用两个麦克风的数据做波束成形
// 增强正前方声源，抑制其他方向噪声
void beamforming(int16_t* mic1, int16_t* mic2, int16_t* output, size_t count) {
    for (size_t i = 0; i < count; i++) {
        // 简单延迟求和波束成形
        output[i] = (mic1[i] + mic2[i]) / 2;
    }
}
```

**自动增益控制（AGC）：**

```cpp
// 自动调整输入增益，使语音保持在合适的电平范围
void automaticGainControl(int16_t* samples, size_t count, float targetRMS) {
    float currentRMS = calculateRMS(samples, count);
    float gain = targetRMS / currentRMS;
    
    // 限制增益范围
    gain = constrain(gain, 0.5f, 4.0f);
    
    for (size_t i = 0; i < count; i++) {
        samples[i] = (int16_t)(samples[i] * gain);
    }
}
```

## 常见问题

**Q: 为什么选择 16kHz 而不是 44.1kHz？**  
A: 语音识别主要关注 300Hz-3.4kHz 范围，16kHz 已足够（奈奎斯特频率 8kHz）。更高采样率会增加数据量和延迟。

**Q: VAD 总是误触发怎么办？**  
A: 提高 `VAD_RMS_THRESHOLD`，或增加 `VAD_MIN_SPEECH_MS` 避免短促噪声触发。

**Q: 录音有底噪怎么办？**  
A: 检查接地和屏蔽，降低麦克风增益，或在数字域做高通滤波（切除<300Hz）。

**Q: 播放声音太小？**  
A: 检查 TTS 输出音量、ES8311 寄存器配置、功放控制引脚（GPIO15）。
