## 1.5.1 数组与链表

### 数组（Array）

**数组是什么？** 数组是相同类型元素的有序集合，通过索引访问。

```cpp
// 声明和初始化
int numbers[5] = {10, 20, 30, 40, 50};

// 访问元素（索引从 0 开始）
int first = numbers[0];     // 10
int third = numbers[2];     // 30

// 修改元素
numbers[0] = 100;

// 遍历数组
for (int i = 0; i < 5; i++) {
    Serial.println(numbers[i]);
}
```

**数组的特点：**

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 访问 | O(1) | 通过索引直接访问 |
| 插入 | O(n) | 可能需要移动元素 |
| 删除 | O(n) | 可能需要移动元素 |
| 查找 | O(n) | 需要遍历 |

**内存布局：**
```
numbers[5] = {10, 20, 30, 40, 50}

内存地址：[10][20][30][40][50]
          ^连续存储^
```

**ESP32 上的数组：**

```cpp
// 小数组可以用栈内存
int smallArray[10];

// 大数组建议用 PSRAM
uint8_t* largeArray = (uint8_t*)ps_malloc(100000);
if (largeArray == NULL) {
    Serial.println("PSRAM 不足");
}

// 使用完毕释放
free(largeArray);
```

### 链表（Linked List）

**链表是什么？** 链表由节点组成，每个节点包含数据和指向下一个节点的指针。

```cpp
// 节点结构
struct Node {
    int data;
    Node* next;
};

// 创建链表
Node* head = NULL;

// 在头部插入节点
void insertAtHead(int value) {
    Node* newNode = new Node;
    newNode->data = value;
    newNode->next = head;
    head = newNode;
}

// 遍历链表
void traverse() {
    Node* current = head;
    while (current != NULL) {
        Serial.println(current->data);
        current = current->next;
    }
}

// 删除节点
void deleteNode(int value) {
    Node* current = head;
    Node* prev = NULL;
    
    // 找到要删除的节点
    while (current != NULL && current->data != value) {
        prev = current;
        current = current->next;
    }
    
    if (current == NULL) return;  // 没找到
    
    // 删除
    if (prev == NULL) {
        head = current->next;  // 删除头节点
    } else {
        prev->next = current->next;
    }
    delete current;
}
```

**链表的特点：**

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 访问 | O(n) | 需要遍历 |
| 插入 | O(1) | 头部插入 |
| 删除 | O(1) | 头部删除 |
| 查找 | O(n) | 需要遍历 |

**内存布局：**
```
head -> [data|next] -> [data|next] -> [data|next] -> NULL
         ↓              ↓              ↓
       分散在内存各处，通过指针连接
```

### 数组 vs 链表

| 特性 | 数组 | 链表 |
|------|------|------|
| 内存 | 连续 | 分散 |
| 随机访问 | 快 O(1) | 慢 O(n) |
| 插入/删除 | 慢 O(n) | 快 O(1) |
| 内存效率 | 高 | 低（需要额外指针） |
| 适用场景 | 查找多 | 增删多 |

**项目中的实际应用：**

```cpp
// 数组：存储固定的表情序列
const CatExpression表情序列 [] = {CAT_NEUTRAL, CAT_HAPPY, CAT_THINKING};

// 链表（或队列）：存储待处理的触摸事件
struct TouchEvent {
    Gesture gesture;
    uint32_t timestamp;
    TouchEvent* next;
};
```

## 1.5.2 队列与栈

### 队列（Queue）

**队列是什么？** 队列是 FIFO（先进先出）的数据结构。

```
入队 → [A] → [B] → [C] → 出队
      队尾           队头
```

**实现示例：**

```cpp
#include <queue>

// STL 队列
std::queue<int> q;

// 入队
q.push(1);
q.push(2);
q.push(3);

// 查看队头
int front = q.front();    // 1

// 出队
q.pop();                  // 移除 1

// 检查是否为空
if (q.empty()) {
    Serial.println("队列为空");
}

// 队列大小
int size = q.size();
```

**ESP32 中的实际应用 - 触摸事件队列：**

```cpp
#include <queue>

struct TouchEvent {
    uint8_t gesture;
    uint32_t timestamp;
};

std::queue<TouchEvent> touchQueue;

// 中断处理程序中添加事件（简化版）
void onTouchDetected(uint8_t gesture) {
    TouchEvent event;
    event.gesture = gesture;
    event.timestamp = millis();
    touchQueue.push(event);
}

// 主循环处理事件
void loop() {
    while (!touchQueue.empty()) {
        TouchEvent event = touchQueue.front();
        touchQueue.pop();
        handleTouchEvent(event);
    }
}
```

### 栈（Stack）

**栈是什么？** 栈是 LIFO（后进先出）的数据结构。

```
        栈顶
         ↓
push →  [C]
        [B]
        [A]
```

**实现示例：**

```cpp
#include <stack>

// STL 栈
std::stack<int> s;

// 入栈
s.push(1);
s.push(2);
s.push(3);

// 查看栈顶
int top = s.top();      // 3

// 出栈
s.pop();                // 移除 3

// 检查是否为空
if (s.empty()) {
    Serial.println("栈为空");
}
```

**ESP32 中的实际应用 - 函数调用栈：**

```cpp
// 每次函数调用都会在栈上分配局部变量
void deepFunction(int level) {
    int localVar = level;  // 在栈上
    if (level > 0) {
        deepFunction(level - 1);  // 递归调用
    }
}

// 注意：ESP32 栈空间有限（约 8KB/任务），避免深度递归
```

## 1.5.3 哈希表

**哈希表是什么？** 哈希表通过哈希函数实现快速的键值对存储和查找。

```cpp
#include <unordered_map>

// 创建哈希表
std::unordered_map<String, int> deviceMap;

// 插入
deviceMap["device-001"] = 100;
deviceMap["device-002"] = 200;

// 查找
int value = deviceMap["device-001"];    // 100

// 检查是否存在
if (deviceMap.count("device-001")) {
    Serial.println("设备存在");
}

// 删除
deviceMap.erase("device-001");

// 遍历
for (auto& pair : deviceMap) {
    Serial.printf("%s: %d\n", pair.first.c_str(), pair.second);
}
```

**哈希表的特点：**

| 操作 | 平均时间复杂度 | 最坏情况 |
|------|--------------|---------|
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

**项目中的实际应用 - 设备会话管理：**

```cpp
// 存储每个设备的会话数据
struct SessionData {
    String deviceId;
    uint32_t lastActive;
    std::vector<String> history;
};

std::unordered_map<String, SessionData*> sessions;

// 获取或创建会话
SessionData* getOrCreateSession(String deviceId) {
    if (sessions.find(deviceId) == sessions.end()) {
        sessions[deviceId] = new SessionData();
        sessions[deviceId]->deviceId = deviceId;
    }
    sessions[deviceId]->lastActive = millis();
    return sessions[deviceId];
}
```

## 1.5.4 枚举与状态机

### 枚举（Enum）

**枚举是什么？** 枚举是一组命名的常量。

```cpp
// 传统枚举
enum CatExpression {
    CAT_NEUTRAL = 0,    // 0
    CAT_HAPPY,          // 1
    CAT_LISTENING,      // 2
    CAT_THINKING,       // 3
    CAT_SLEEPY,         // 4
    CAT_TALKING,        // 5
    CAT_EXPR_COUNT      // 6（用于边界检查）
};

// 使用
CatExpression currentExpr = CAT_HAPPY;

if (currentExpr == CAT_HAPPY) {
    // 处理开心状态
}

// 数组配合枚举
const char* exprNames[] = {
    "Neutral", "Happy", "Listening", 
    "Thinking", "Sleepy", "Talking"
};
Serial.println(exprNames[currentExpr]);
```

**C++11 枚举类（类型安全）：**

```cpp
enum class Emotion : uint8_t {
    Neutral = 0,
    Happy,
    Thinking,
    Sleepy
};

Emotion emo = Emotion::Happy;

// 转换为整数
uint8_t value = static_cast<uint8_t>(emo);
```

### 状态机（State Machine）

**状态机是什么？** 状态机是一种模型，系统在任何时刻都处于有限状态之一，根据输入进行状态转换。

**项目中的实际应用 - 对话状态机：**

```cpp
// 定义状态
enum DialogState {
    STATE_IDLE,         // 空闲
    STATE_LISTENING,    // 录音中
    STATE_THINKING,     // 等待 AI 回复
    STATE_TALKING,      // 播放 TTS
};

// 状态变量
DialogState currentState = STATE_IDLE;

// 状态转换函数
void transitionTo(DialogState newState) {
    // 退出当前状态的清理工作
    switch (currentState) {
        case STATE_LISTENING:
            stopRecording();
            break;
        case STATE_TALKING:
            stopPlayback();
            break;
    }
    
    // 进入新状态的初始化
    switch (newState) {
        case STATE_IDLE:
            catFace.setExpression(CAT_NEUTRAL);
            break;
        case STATE_LISTENING:
            catFace.setExpression(CAT_LISTENING);
            startRecording();
            break;
        case STATE_THINKING:
            catFace.setExpression(CAT_THINKING);
            processAIRequest();
            break;
        case STATE_TALKING:
            catFace.setExpression(CAT_TALKING);
            playTTS();
            break;
    }
    
    currentState = newState;
}

// 状态处理
void loop() {
    switch (currentState) {
        case STATE_IDLE:
            handleIdle();
            break;
        case STATE_LISTENING:
            handleListening();
            break;
        case STATE_THINKING:
            handleThinking();
            break;
        case STATE_TALKING:
            handleTalking();
            break;
    }
}
```

**状态转换图：**

```
                    长按
    +----------------------------------+
    |                                  |
    v                                  |
[LISTENING] --VAD 完成--> [THINKING] --AI 回复--> [TALKING] --播放完成--> [IDLE]
    ^                                  |
    |                                  |
    +----------点击取消----------------+
```

**带超时的状态机：**

```cpp
// 状态超时处理
uint32_t stateStartTime = 0;
const uint32_t LISTENING_TIMEOUT = 30000;  // 30 秒

void transitionTo(DialogState newState) {
    currentState = newState;
    stateStartTime = millis();
}

void handleListening() {
    // 检查超时
    if (millis() - stateStartTime > LISTENING_TIMEOUT) {
        Serial.println("录音超时");
        transitionTo(STATE_IDLE);
        return;
    }
    
    // 正常处理
    processAudio();
}
```

## 常见问题

**Q: 什么时候用数组，什么时候用链表？**  
A: 如果元素数量固定且主要进行随机访问，用数组。如果需要频繁插入/删除且元素数量不固定，用链表。

**Q: ESP32 上哈希表占用内存大吗？**  
A: `std::unordered_map` 有一定开销，每个元素约占用几十字节。大量数据时建议用 PSRAM。

**Q: 状态机和 if-else 有什么区别？**  
A: 状态机结构清晰、易于维护和扩展，特别是状态多、转换复杂时。if-else 适合简单的条件判断。
