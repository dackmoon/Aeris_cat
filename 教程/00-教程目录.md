## 教程概述

本教程系统地讲解 **Cyber Cat AI 伴生机猫** 项目的完整开发过程，涵盖从基础到进阶的全部知识。

**目标读者：**
- 嵌入式开发者（想学习 AIoT 项目）
- Python 开发者（想了解硬件交互）
- 学生/爱好者（想完成一个完整的智能硬件项目）

**前置要求：**
- 基础编程经验（任何语言）
- 一台电脑（Windows/Mac/Linux）
- 一套 ESP32-S3 开发设备

## 学习建议

### ✅ 推荐做法

1. **按顺序学习**：基础篇 → 架构篇 → 实战篇 → 进阶篇
2. **动手实践**：每章的代码都要亲自运行
3. **做笔记**：记录遇到的问题和解决方案
4. **提问前搜索**：很多问题 FAQ 已有答案
5. **分享成果**：写博客、发视频，教是最好的学

### ❌ 避免做法

1. **只看不练**：教程不是小说，要动手写代码
2. **跳过基础**：基础不牢，后面会卡住
3. **盲目复制**：理解代码再复制，不要无脑粘贴
4. **遇到问题就放弃**：调试是学习的一部分
